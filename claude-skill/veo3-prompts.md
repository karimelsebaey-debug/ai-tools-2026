# Google Veo 3 — Prompt Engineering Skill

> Source: `DareDev256/Ultimate-Image-Video-Prompt-Generator`, `duyuanchao/video-prompt-engineering-guide`

## Prompt Formula

```
[Visual Description] + [Action] + [Camera/Shot Type] + [Lighting & Atmosphere] + [Style Reference] + [Audio/Sound Cue (Veo 3 unique)]
```

> **Veo 3 Unique Feature:** Supports native audio description in prompts — sound effects, music mood, ambient audio.

## Core Capabilities

| Feature | Detail |
|---------|--------|
| Resolution | Up to 4K |
| Duration | Up to 60 seconds |
| Audio | Native sound generation from prompt |
| Physics | Advanced realistic motion & physics |
| Style | Photorealistic to stylized |

## Prompt Templates

### Cinematic with Audio (Veo 3 Exclusive)
```
[Scene description], [camera movement], [lighting],
[style], with [sound: ambient crowd noise / rain / orchestral music / silence]
```

### Documentary Style
```
A [subject] in [location], natural handheld camera, available light,
real-world textures, documentary aesthetic, ambient sound of [environment]
```

### Commercial / Brand
```
[Product] in [context], [mood lighting], smooth professional camera movement,
upbeat background music, clean and modern, 16:9 commercial format
```

### Action / Sports
```
[Athlete/Subject] performing [action] in [location], dynamic tracking shot,
slow motion at peak moment, crowd cheering in background, high energy, sports broadcast style
```

## Shot Type Keywords

```
extreme wide shot (EWS) | wide shot (WS) | medium shot (MS)
close-up (CU) | extreme close-up (ECU) | over-the-shoulder (OTS)
bird's eye view | worm's eye view | Dutch angle
```

## Audio Prompt Examples (Veo 3 Only)

```
"...with the sound of gentle ocean waves and distant seagulls"
"...accompanied by a soft piano melody"
"...with intense orchestral music building to a crescendo"
"...in complete silence, only subtle wind"

```


## Do's and Don'ts

| Do | Don't |
|----|-------|
| Include audio descriptions | Ignore the audio layer |
| Use cinematic shot terminology | Use vague motion words |
| Reference real film styles | Overuse superlatives (amazing, perfect) |
| Describe lighting precisely | Write only about subject appearance |
| Keep under 200 words | Exceed prompt length limits |
